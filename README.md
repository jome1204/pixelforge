# PixelForge

PixelForge is an original C++17 raster-image processing library designed for
bounded parsing and sanitizer-guided fuzzing. The current implementation
contains the common image model, checked pixel allocation, metadata and palette
handling, format detection, BMP decoding and encoding, TIFF/BigTIFF directory
parsing, and geometric image transformations.

This repository is under active development. PNG pixel decoding, TIFF strip and
tile decoding, the PixelForge tiled format, validation tools, tests, seed
corpora, and ClusterFuzzLite harnesses are being completed before submission.
